# Security Policy

## Supported versions

Security fixes are released for the latest version of the Bisht Academic Theme.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report it privately using GitHub's **Report a vulnerability** button on the **Security** tab of this repository, or through [digitalbisht.com](https://digitalbisht.com/).

Please include the OJS version, the theme version, and steps to reproduce. You will get a reply as soon as possible, and a fixed release will be published once the issue is confirmed.
